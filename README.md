# FlyBY

FlyBY is a micro Python application that displays real-time flight information for planes currently flying overhead. Using your current location, it queries nearby aircraft and presents a readable snapshot of what’s in the sky above you.

---

🚀 Features
• Detects your location via IP \*IP address is not stored
• Displays flights flying overhead, including:
• Callsign
• Altitude
• Origin and destination
• Aircraft type
• Simple CLI output
• Modular and easily extensible

---

📦 Requirements
• Python 3.8+
• requests
• geocoder

---

Install dependencies:

```
pip install -r requirements.txt
```
